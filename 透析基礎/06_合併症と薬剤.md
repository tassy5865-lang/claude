# 06. 合併症と薬剤

透析患者に起こりやすい合併症と、その管理に使われる代表的な薬剤カテゴリを整理する。
具体的な投与量(mg数など)は患者ごとの個別判断・処方医の裁量が大きい領域のため、ここでは扱わない。

## 透析中に起こりやすい合併症(急性)

| 合併症 | 概要 |
|---|---|
| 血圧低下(透析中低血圧) | 除水による循環血液量の急激な減少が主因。冷汗・悪心・意識朦朧などを伴うことがある |
| 不均衡症候群 | 急速な血中老廃物の除去により、脳内と血中の浸透圧差が生じ、頭痛・悪心・けいれんなどをきたす状態。導入初期の急速な透析で起こりやすい |
| 筋けいれん(こむら返り) | 過度な除水・電解質変動などが誘因 |
| 掻痒感 | 尿毒症物質の蓄積、皮膚の乾燥、CKD-MBDなどが関与するとされる |
| 発熱・悪寒 | 感染症や回路・穿刺部由来のトラブルを疑う所見 |
| シャントトラブル | 穿刺部からの出血、シャント閉塞・狭窄によるスリル/シャント音の低下など |
| 不整脈 | 電解質(特にK・Ca)の急激な変動が誘因となることがある |

## 透析患者に多い長期合併症

| 合併症 | 概要 | 関連セクション |
|---|---|---|
| 腎性貧血 | エリスロポエチン産生低下による貧血 | [05_検査値と指標.md](05_検査値と指標.md) |
| CKD-MBD(骨・ミネラル代謝異常) | P・Ca・PTHの異常による骨病変・血管石灰化 | [05_検査値と指標.md](05_検査値と指標.md) |
| 心血管疾患 | 透析患者の主要な死因の一つ。高血圧・体液過剰・血管石灰化などが背景 | — |
| 透析アミロイドーシス | β2-ミクログロブリンなど中分子物質の蓄積による関節症状など。長期透析患者に多い | — |
| 感染症 | 免疫機能低下、バスキュラーアクセス由来の感染リスクなど | — |
| フレイル・サルコペニア | 高齢の透析患者で問題となりやすい筋力・身体機能の低下 | — |

## 主な薬剤カテゴリ

透析患者の管理で用いられる代表的な薬剤群。個々の薬剤名・用量は処方情報を都度確認する。

| カテゴリ | 目的 | 代表例(一般名/分類) |
|---|---|---|
| ESA製剤(赤血球造血刺激因子) | 腎性貧血の改善 | エリスロポエチン製剤など |
| 鉄剤 | 鉄欠乏の補正(ESAの効果を高める) | 経口鉄剤、静注鉄剤 |
| リン吸着薬 | 高リン血症の是正 | Ca含有/非含有リン吸着薬など |
| 活性型VD3製剤 | PTHの抑制。P・Caを上げうるため高値の場合は増量注意 | マキサカルシトール(オキサロール)など |
| カルシミメティクス | PTH・Caをともに低下させる。Ca低値の場合は減量/休薬を検討 | エボカルセト、エテルカルセチドなど |
| 抗凝固薬 | 透析回路内の血液凝固を防止 | ヘパリンなど |
| 降圧薬 | 体液過剰・レニン-アンジオテンシン系亢進などによる高血圧の管理 | 各種降圧薬(患者の病態に応じて選択) |

各薬剤の作用機序と検査値の関係は [05_検査値と指標.md](05_検査値と指標.md) のCKD-MBD・貧血の項目と合わせて理解すると整理しやすい。
