# 03. 透析の仕組みと回路

血液透析(HD)を実施するための物理的な仕組み(回路・ダイアライザー・バスキュラーアクセス)を整理する。

## 血液回路の全体像

患者の血管 →(脱血)→ 血液ポンプ → ダイアライザー → (返血)→ 患者の血管、という循環を体外循環で作る。

| 構成要素 | 役割 |
|---|---|
| 脱血側回路 | 患者から血液を体外に導く側のライン |
| 血液ポンプ | 回路内で血液を一定流量で送り出す |
| 抗凝固薬(ヘパリンなど)注入ライン | 体外循環中の血液凝固を防ぐため回路内に持続注入 |
| エアトラップチャンバー(気泡除去) | 回路内の空気を検知・除去し、空気塞栓を防止 |
| ダイアライザー | 血液と透析液を半透膜越しに接触させる中心部分(下記) |
| 返血側回路 | ダイアライザーを通過した血液を患者に戻す側のライン |
| 各種センサー・警報装置 | 静脈圧・気泡・漏血などを監視し、異常時に自動停止する安全機構 |

## ダイアライザー(人工腎臓)

- 内部に**中空糸膜**(細いストロー状の半透膜)を数千〜1万本以上束ねた構造
- 血液は中空糸の内側、透析液は外側を流れ、向流(逆方向)で接触することで拡散効率を高める
- 膜面積・膜素材(セルロース系/合成高分子系など)により除去性能が異なり、患者の体格や除去したい物質の分子量に応じて選択する

### 膜の性能分類

出典: 日本透析医学会「血液浄化器(中空糸型)の機能分類2013」(透析会誌46(5):501-506, 2013)

「I型〜V型」という呼び方には、以下の2つの異なる分類が存在するため区別が必要。

**(1) 診療報酬上の機能区分**(β2-ミクログロブリン(β2-MG)クリアランスのみによる5段階区分。臨床現場で単に「I型〜V型」と言う場合は通常こちら)

| 区分 | β2-MGクリアランス |
|---|---|
| I型 | 10 mL/min未満 |
| II型 | 10以上30 mL/min未満 |
| III型 | 30以上50 mL/min未満 |
| IV型 | 50以上70 mL/min未満 |
| V型 | 70 mL/min以上 |

- 日本ではIV型・V型(いわゆるhigh-flux/super high-flux膜相当)の使用が突出しており(合計で全体の9割超)、欧米諸国とは異なる本邦特有の傾向とされる。

**(2) 学会機能分類2013**(血液透析器はI型/II型/S型のいずれか1つに分類。I型・II型はさらにアルブミンふるい係数でa/b型に細分)

| 型 | β2-MGクリアランス | アルブミンふるい係数(SC、BCG法) |
|---|---|---|
| I-a型(蛋白非透過/低透過型) | 70 mL/min未満 | 0.03未満 |
| I-b型(蛋白透過型) | 70 mL/min未満 | 0.03以上 |
| II-a型(蛋白非透過/低透過型) | 70 mL/min以上 | 0.03未満 |
| II-b型(蛋白透過型) | 70 mL/min以上 | 0.03以上 |
| S型 | 生体適合性に優れ、吸着によって溶質除去できる・抗炎症性・抗酸化性を有するなど特別な機能をもつもの(β2-MGクリアランス等では特徴を表現しきれないもの) | — |

- 2025年時点でS型はEVAL膜・PMMA膜のダイアライザーが該当。
- 測定条件(血流量QB=200±4 mL/min、透析液流量QD=500±15 mL/min、膜面積A=1.5m²)を揃えたうえでの基準値であり、条件が異なれば数値も変わる点に注意。
- 国際的な「low-flux/high-flux」という呼び方は主にKUF(限外濾過係数)で区分されることが多く、上記の日本の学会分類(β2-MGクリアランス+アルブミン透過性が軸)とは分類軸が異なる。

## バスキュラーアクセス(血液の出入り口)

安定して大量の血液を体外循環させるための血管の通り道。

| 種類 | 概要 |
|---|---|
| 自己血管内シャント(AVF) | 自分の動脈と静脈を皮下でつなぎ合わせ、静脈を発達させて穿刺に使う。最も標準的で長期使用に適する |
| 人工血管内シャント(AVG) | 自己血管が使えない場合に人工血管を移植してシャントを作る |
| 表在化動脈 | 動脈自体を皮下浅くに移動させて穿刺しやすくする方法(シャント作成が難しい場合など) |
| 血液透析用カテーテル | 中心静脈に直接カテーテルを留置する方式。緊急導入時や上記が使えない場合に使用。短期用・長期用(カフ付き)がある |

- 穿刺は基本的に2本の針(脱血用・返血用)を用いる(一部カテーテルは針不要)
- シャントは日々の自己管理(スリル・シャント音の確認など)と定期的な機能評価が重要
- シャントの血管解剖・視診/触診/聴診による観察のポイント・トラブル(脱血不良、静脈圧上昇、再循環など)の詳細は [09_シャント管理とトラブル対応.md](09_シャント管理とトラブル対応.md) を参照
- 透析中に発生する警報アラームへの対応は [10_透析中の警報アラーム対応.md](10_透析中の警報アラーム対応.md) を参照

## 透析条件(設定項目)

実際の透析では、患者の体格・病態・アクセスの状態に応じて以下のような項目を個別に設定する。数値は施設・患者によって幅があるため、目安として記載する。

| 項目 | 内容 | 目安 |
|---|---|---|
| 血流量(QB) | 血液ポンプの送血速度 | 一般に150〜250 mL/min程度(施設差あり) |
| 透析液流量(QD) | ダイアライザーに流す透析液の速度 | 一般に500 mL/min程度(施設差あり) |
| 透析時間 | 1回あたりの透析にかける時間 | 一般に4時間前後×週3回が標準的(個別に調整) |
| 除水量 | 1回の透析で除去する体液量 | ドライウェイトと透析前体重の差から設定 |
| 抗凝固薬の種類・量 | 出血リスクなどに応じて選択 | 患者の状態により個別設定 |

これらの条件と、透析の質を評価する指標(Kt/V、URRなど)との関係は [05_検査値と指標.md](05_検査値と指標.md) で扱う。
