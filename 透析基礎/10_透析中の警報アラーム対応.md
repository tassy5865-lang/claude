# 10. 透析中の警報アラーム対応

出典: `透析警報アラーム研修資料_全体版 - 修復済み.pptx`(透析未経験看護師・新人臨床工学技士向け研修資料)を基に整理。
各アラームを「原因→確認→対応」の共通フォーマットで解説する。

## なぜアラーム対応を学ぶのか

透析は体外循環という特性上、対応の遅れがそのまま致死的な合併症につながり得る。

| 想定される致死的合併症 | 内容 |
|---|---|
| 大量出血 | 抜針・回路離断が起きると短時間で大量出血につながる |
| 回路閉塞・凝血 | 対応が遅れると生命維持(血液浄化)そのものができなくなる |
| 空気塞栓 | 微量の気泡でも心臓・脳に達すれば重篤化しうる |
| 血圧低下・ショック | 除水や体外循環により循環動態が急変することがある |

アラームは、これらの致死的合併症を未然に防ぐための「最後の砦」。

## 透析回路の基本構造(前提知識)

各アラームを理解するための土台。詳細は [03_透析の仕組みと回路.md](03_透析の仕組みと回路.md) も参照。

| 構成 | 役割 |
|---|---|
| 脱血側(動脈側・A) | 患者から血液を体外に引き出すライン。血液ポンプの吸引力がかかる区間 |
| 返血側(静脈側・V) | ダイアライザを通った血液を体内に戻すライン |
| ダイアライザ(人工腎臓) | 半透膜を介して老廃物・余分な水分を除去する回路の中心部品 |
| 安全装置 | 気泡検知器・血液漏れ検知器など。異常を検知し自動でポンプを停止させる |

## 各アラームの原因・確認・対応

### 静脈圧上限アラーム(圧力系)

- **原因**: 静脈側(返血路)のどこかで抵抗が生じている可能性(屈曲・穿刺針の位置ずれ・凝血など)
- **確認**: Vチャンバ → 気泡検知器 → クランプ → 穿刺部の順に確認
- **対応**: 是正後に再開。改善なければ返血準備・報告

**発生タイミング別の原因整理**(「いつ鳴ったか」で疑うべき原因の重みが変わる)

| タイミング | 疑う原因 |
|---|---|
| 透析開始時 | 回路の折れ、ラインクランプを閉めている、針先の凝固、針先が血管壁に当たっている |
| 透析中 | 回路の折れ、針先の凝固、針先が血管壁に当たっている、回路(チャンバ)内の凝固、腕を曲げた |

**確認と対処の流れ**(上から順に1つずつ確認し、該当したら対処)

1. 回路の屈曲・腕の角度 → 屈曲を解除する、腕を伸ばす
2. Vチャンバの凝血(**穿刺トラブルが原因の8割**ともいわれる。他に脱血不良による気泡発生→凝固促進、炎症反応(CRP)、過濃縮も) → 軽度なら生食洗浄で経過観察。完全凝固し継続困難ならV側回路のみ交換
3. 針先の凝血・血管壁への接触 → 生食洗浄、向きを調整、改善なければ再穿刺
4. 穿刺部より中枢側の狭窄 → 穿刺部の変更を検討、エコー評価のうえ必要ならPTA(経皮的血管形成術)を検討
5. 再循環の可能性 → 再循環を疑う所見があれば評価する([09_シャント管理とトラブル対応.md](09_シャント管理とトラブル対応.md)参照)

### 静脈圧下限アラーム(圧力系)

- **原因**: 穿刺針の抜けかけ・回路接続部の外れなど、出血につながる異常の可能性。血流量設定の低下、脱血不良、Vチャンバまでの回路での凝固
- **確認**: 穿刺部・接続部からの出血の有無 → 凝固の有無 → 血流量設定 → 各接続部の緩み
- **対応**: 出血があれば直ちに圧迫止血・ポンプ停止。接続の緩みは増し締め。改善なければ医師へ報告

**確認と対処の流れ**

1. 脱血不良(穿刺トラブル・抜針) — ★血圧が下がる→循環血流速が落ちる→脱血不良、という経路もあるためバイタル・患者状態もあわせて確認 → 針先を修正、必要であれば再穿刺、血流量(Qb)を落とす
2. Vチャンバまでの回路の屈曲 → 確認して屈曲を解除する
3. Vチャンバまでの凝固(ダイアライザ内含む。毎回決まったタイミングで補液することも凝血対策になる) → 膜素材が合わなければ変更、ヘパリン量が少なければ見直し(炎症反応があれば一時的に増量)
4. 回路接続の緩み・クランプ忘れ → 接続とクランプを確認し是正、あわせて患者状態・バイタルを確認

### 透析液圧低下アラーム(透析液系)

- **原因**: 脱血不良、透析液回路のリーク、供給ポンプ故障
- **確認**: 針先の確認 → 透析液ラインの接続・リーク → 装置の自己診断表示
- **対応**: 針先の修正、必要であれば再穿刺。補液速度を落とす。機器点検・報告

### 気泡検知器作動アラーム(安全装置系)

回路内に気泡が混入している可能性 — ただちにポンプ停止を確認。

- **原因**: 回路接続部の緩み、脱血不良による微小気泡、補液ボトルの空打ち
- **確認**: ポンプ自動停止 → 気泡の位置・量 → 接続部の緩み → 患者の自覚症状
- **対応**: 気泡を安全に除去後に再開。改善なければ医師へ報告

### TMP(膜間圧力差)異常上昇アラーム(圧力系)

ダイアライザ内で血液側・透析液側の圧較差が広がっている可能性。

- **原因**: ダイアライザ内凝血・除水量設定過多・フィルター目詰まり
- **確認**: 回路内の血液の色調・凝血塊 → 抗凝固剤(ヘパリン)投与量 → 除水設定
- **対応**: 抗凝固剤の見直し。改善なければダイアライザ交換・報告
- 透析液圧上限アラームが併発することもある

### 血液漏れ検知器作動アラーム(安全装置系)

ダイアライザの膜破損が疑われる — 排液の性状を確認。

- **原因**: ダイアライザ内部の膜破損、気泡による誤検知
- **確認**: 排液の目視で血性の有無 → 継続の有無 → ダイアライザ使用時間
- **対応**: 陽性ならダイアライザ交換。回路内血液は返血せず廃棄を検討(医師判断)

## 緊急度別の初動フローチャート

アラームが鳴ったら、まず「命に関わるか」で初動を分ける。

```
アラームが鳴った
  │
  ├─ 生命に関わる兆候があるか?(出血・意識レベル低下・重度血圧低下 など)
  │
  ├─ はい → 緊急対応(ただちに)
  │         ・ただちに血液ポンプを停止
  │         ・圧迫止血・体位保持など応急処置
  │         ・医師・当直CEへ緊急連絡
  │         ・バイタルサインを測定・記録
  │
  └─ いいえ → 通常対応(まず確認 → 是正)
            ・表示内容と回路を確認
            ・該当箇所を是正(屈曲直し・接続確認 等)
            ・是正後にポンプを再開
            ・改善しなければ医師/CEへ報告
```

同じアラームでも状況により緊急度は変わる。**判断に迷ったら、常に「緊急対応」を優先する。**

## よくある誤対応・ヒヤリハット事例

「よくあること」という思い込みが、対応の遅れにつながる。

| 事例 | 内容 | 教訓 |
|---|---|---|
| 抜針アラームへの対応遅れ | アラーム音を「体動による誤作動だろう」と判断し、目視確認を数分後回しにした | 出血の可能性がある限り、確認より先に「止める・見る」を最優先する |
| 頻回の静脈圧上昇を軽視 | 同じ患者で毎回鳴るからと原因を確認せず、そのつどリセットを繰り返していた | 頻回に鳴るアラームこそ、穿刺針の位置など根本原因を都度見直す |
| エア検知後、クランプ確認を省略 | ポンプの自動停止だけを確認し、クランプが閉じているかを見ずに気泡を除去しようとした | エア検知時は「ポンプ停止」と「クランプ確認」を必ずセットで行う |
| 原因を確認せずにリセット | 経験の浅さから、表示をリセットして再開することを優先し、原因を確認しなかった | リセットの前に「なぜ鳴ったか」を一呼吸おいて確認する習慣をつける |
