# 01. 腎臓と腎不全

## 腎臓の基本構造

- 腰の高さに左右1つずつ、ソラマメ型(握りこぶし大)
- 最小機能単位は**ネフロン**(糸球体+尿細管)。片腎あたり約100万個
- 糸球体で血液をろ過 → 原尿を生成 → 尿細管で必要な水分・電解質を再吸収 → 尿として排泄

## 腎臓の主な役割

| 機能 | 内容 |
|---|---|
| 老廃物の排泄 | 尿素窒素・クレアチニンなどの代謝産物を尿中に排泄 |
| 水分・電解質の調整 | 体液量、Na・K・Ca・Pなどのバランスを維持 |
| 酸塩基平衡の維持 | 血液のpHを一定範囲に保つ(重炭酸イオンの調整) |
| 血圧の調整 | レニン分泌 → レニン-アンジオテンシン-アルドステロン系(RAA系)で血圧を制御 |
| 造血の促進 | エリスロポエチン(EPO)を分泌し、骨髄での赤血球産生を刺激 |
| 骨代謝への関与 | ビタミンDを活性型に変換し、Ca吸収・骨代謝を調整 |

→ 腎機能が低下すると、これらすべてに影響が及ぶ(尿毒症、浮腫、高血圧、腎性貧血、CKD-MBDなど)。

## 腎不全とは

腎臓の機能が低下し、老廃物の排泄や体液・電解質の調整ができなくなった状態。経過により2つに大別される。

- **急性腎障害(AKI: Acute Kidney Injury)**
  - 数時間〜数日単位で急激に腎機能が低下
  - 原因が除去・治療されれば回復する可能性がある
  - 原因は腎前性(脱水・出血による血流低下)・腎性(薬剤性・腎炎など)・腎後性(尿路閉塞)に分類
- **慢性腎臓病(CKD: Chronic Kidney Disease)**
  - 数ヶ月〜数年かけて緩徐に腎機能が低下し、基本的に元に戻らない
  - 透析導入に至る主な経路

## CKDの定義

以下のいずれかが3ヶ月以上持続する状態(出典: 日本腎臓学会「CKD診療ガイドライン2023」)。

- 腎障害を示す所見(蛋白尿など)が明らか
- GFR(糸球体濾過量) 60 mL/min/1.73m² 未満

## CKDステージ分類(GFR区分)

出典: 日本腎臓学会「CKD診療ガイドライン2023」

| 区分 | GFR (mL/min/1.73m²) | 状態 |
|---|---|---|
| G1 | ≧90 | 正常または高値 |
| G2 | 60〜89 | 正常または軽度低下 |
| G3a | 45〜59 | 軽度〜中等度低下 |
| G3b | 30〜44 | 中等度〜高度低下 |
| G4 | 15〜29 | 高度低下 |
| G5 | <15 | 末期腎不全(ESKD) |

蛋白尿区分(A1〜A3)と組み合わせた重症度分類(ヒートマップ)もガイドラインに掲載されているが、詳細は必要になった時点で追記する。

## 腎不全(透析導入)の主な原因疾患

日本透析医学会の統計調査で報告される代表的な原疾患(年ごとに順位・割合は変動するため、最新の統計調査で確認すること)。

- 糖尿病性腎症
- 腎硬化症(高血圧性)
- 慢性糸球体腎炎
- 多発性嚢胞腎
- その他(慢性腎盂腎炎、膠原病関連など)

## 末期腎不全と透析導入

- CKD G5(GFR <15)まで進行し、保存的治療で症状(尿毒症症状・体液貯留・電解質異常など)がコントロールできなくなった段階で腎代替療法(透析・腎移植)を検討
- 透析導入の判断はGFRの数値だけでなく、症状・臨床所見を総合して行う
