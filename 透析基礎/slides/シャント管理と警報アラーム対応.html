01 PART 1

シャント管理と
トラブル対応

出典: shunt_basics.pptx

バスキュラーアクセス

VA(バスキュラーアクセス)とは

血液浄化(血液透析など)を施行するために必要な、血液の出入り口。血液透析患者にとって必要不可欠なもの。

AVF
自己血管内シャント

動脈と静脈を外科的に吻合。動脈血流が直接静脈へ流入。最も割合が多く、開存性に優れる。

AVG
人工血管内シャント

人工血管を移植して動静脈をそれぞれ吻合。動静脈が細くAVFが作製できない場合に適応。

動脈表在化
非シャント

動脈を皮下浅くに移動し穿刺しやすくする。短絡は作らず返血用静脈が別途必要。心機能不良などで適応。

超音波検査はVAの機能・形態を評価し、管理・治療方針に活用する情報を提供する。

基礎知識

血管解剖(上肢)

VAの構造・異常部位を把握するための土台となる知識。

動脈

鎖骨下動脈 → 腋窩動脈 → 上腕動脈 → 橈骨動脈・尺骨動脈 → 深掌動脈弓・浅掌動脈弓

静脈

表在静脈(吻合部に使用): 橈側皮静脈(AVFでよく使用)・尺側皮静脈・副橈側皮静脈・肘正中皮静脈

深部静脈: 腕頭静脈 ← 鎖骨下静脈 ← 腋窩静脈 ← 上腕静脈 ← 橈骨静脈・尺骨静脈

日常観察

身体所見によるシャント観察

視診・触診・聴診によって、血流の程度や病変部位をおおまかに推測できる。

👁 視診

腫脹・色調・膨隆など、見た目の変化を確認する

✋ 触診

スリル(振動)を3本指で全体評価、1本指で局所評価する

👂 聴診

シャント音の性状(音の高さ・強さ)を聴取する

所見のみでは確定診断はできない。異常を疑う場合は超音波検査による精密評価と組み合わせる。

観察 1/3

視診で見るポイント

所見疑われる病態
腫脹・皮下血管拡張・顔面浮腫静脈高血圧症
手指の潰瘍形成スチール症候群 / 静脈高血圧症(ソアサム症候群)
発赤感染 / 血栓性静脈炎 / 接触性皮膚炎
膨隆真性瘤 / 仮性瘤 / 血管の蛇行 / 血腫 / 感染
手指・爪の色調不良スチール症候群 / 末梢循環障害
観察 2/3

触診で見るポイント

所見疑われる病態
拍動性(断続的)に触知中枢側の狭窄・閉塞
局所のスリルを触知その近傍の狭窄(1本指で評価)
スリルの減弱・血管の虚脱末梢側の狭窄・閉塞
血管そのものが硬い血栓形成・石灰化沈着・壁在血栓
スリル・拍動が消失シャント閉塞

スリルは3本指で全体評価、1本指で局所評価(狭窄が疑われる部位の特定)を行う。

観察 3/3

聴診で見るポイント

所見疑われる病態
高調音その部位の狭窄病変
拍動音(断続的)中枢側の狭窄・閉塞病変
中枢側まで届く大きな音過剰血流
微弱な音低血圧 / 脱水 / 動脈硬化 など

高調音が聴取されても狭窄がない場合、狭窄があっても高調音を聴取しない場合もあり、所見のみで確定診断はできない。

シャントトラブル

代表的な4つのトラブル

脱血不良

最も多く遭遇する異常所見

静脈圧上昇

返血部位の血管内圧上昇

再循環

返血血液の再脱血、効率低下

止血・穿刺困難

抜針後の止血/穿刺手技の困難

次のスライドから、それぞれの原因を詳しく見ていきます。

トラブル 1/4

脱血不良

所定の血流量がVAから脱血できない状態。透析治療で最も多く遭遇する異常所見のひとつ

  • 1穿刺部位の血流量低下(吻合部〜脱血穿刺部位間の狭窄・閉塞、側副静脈の存在、流入動脈・中枢動脈の狭窄・閉塞、脱水・低血圧・心機能低下などの全身状態)
  • 2穿刺針外套が正しく血管内に留置されていない(狭窄部・血栓・血管壁・静脈弁に先端が当たっているなど)
  • 3透析用血液回路内の異常
トラブル 2/4

静脈圧の上昇

返血部位の血管内圧が上昇すること。

  • 1返血穿刺部(針先近傍)、もしくはより中枢側の狭窄・閉塞
  • 2血液回路内の異常、Qb(血流量)に比して返血穿刺針のサイズが小さい場合
  • 3血管蛇行・隔壁・血管荒廃、または過剰血流による相対的な血管内圧上昇

脱血部と返血部の間に狭窄病変がある場合、静脈圧の異常所見が出にくいことがある(末梢側での脱血・中枢側での返血では静脈圧は上昇しない)。

トラブル 3/4

再循環

返血された血液の一部または大半が、脱血部位から再度透析用血液回路側に引き込まれる現象。

目安

概ね10%以上の再循環率がある場合は原因を精査する

影響

脱血不良に気づきにくくなる / 除水経過に伴う回路内濃縮 / 著しい透析効率の低下

主な要因: 脱血部・返血部の位置関係、その間の血管の狭窄・閉塞など。

トラブル 4/4

止血困難・穿刺困難

止血困難

抜針後の止血に要する時間が長くなる。

・穿刺部位より中枢側の狭窄・閉塞(止血部位の血管内圧上昇)
・抗凝固薬/抗血小板薬の影響
・皮膚の脆弱、血管壁の荒廃、皮膚〜血管の距離が短い等

穿刺困難

血管内の適切な位置に穿刺針を留置することが困難。

内針挿入困難:狭窄・閉塞・壁在血栓・石灰化・血管径/深さ・血流低下
外套が進まない:狭窄・閉塞・血栓・静脈弁・蛇行・隔壁

PART 1 まとめ

シャント管理のポイント

  • 1VAは血液透析の生命線。シャントが使えなければ透析治療自体が継続できない
  • 2短絡を形成する「シャント(AVF/AVG)」と、短絡のない「非シャント」に大別される
  • 3上肢の血管解剖の理解が、VAの構造・異常部位を把握する土台になる
  • 4視診・触診・聴診による日常観察が、トラブルの早期発見につながる
  • 5基礎知識の多職種共有 + 超音波検査による精密評価が、安全な透析管理を支える
02 PART 2

透析中の
警報アラーム対応

出典: 透析警報アラーム研修資料_全体版(修復済み)

なぜ学ぶのか

対応の遅れが致死的合併症につながる

透析は体外循環という特性上、対応の遅れがそのまま致死的な合併症につながり得る。

大量出血

抜針・回路離断で短時間に大量出血

回路閉塞・凝血

対応が遅れると血液浄化自体が不可能に

空気塞栓

微量の気泡でも心臓・脳に達すれば重篤化

血圧低下・ショック

除水・体外循環による急な循環動態変化

アラームは、これらの致死的合併症を未然に防ぐための「最後の砦」。

前提知識

透析回路の基本構造

構成役割
脱血側(動脈側・A)患者から血液を体外に引き出すライン。血液ポンプの吸引力がかかる区間
返血側(静脈側・V)ダイアライザを通った血液を体内に戻すライン
ダイアライザ(人工腎臓)半透膜を介して老廃物・余分な水分を除去する回路の中心部品
安全装置気泡検知器・血液漏れ検知器など。異常を検知し自動でポンプを停止
アラーム 1/2

静脈圧上限アラーム(圧力系)

静脈側(返血路)のどこかで抵抗が生じている可能性(屈曲・穿刺針の位置ずれ・凝血など)

  • 1回路の屈曲・腕の角度 → 屈曲を解除、腕を伸ばす
  • 2Vチャンバの凝血(穿刺トラブルが原因の8割とも) → 軽度なら生食洗浄、完全凝固ならV側回路のみ交換
  • 3針先の凝血・血管壁への接触 → 生食洗浄・向き調整、改善なければ再穿刺
  • 4穿刺部より中枢側の狭窄 → 穿刺部変更、エコー評価のうえPTA検討
アラーム 2/2

静脈圧下限アラーム(圧力系)

穿刺針の抜けかけ・回路接続部の外れなど、出血につながる異常の可能性がある。

  • 1脱血不良(穿刺トラブル・抜針) — 血圧低下→循環血流速低下→脱血不良の経路もあり、バイタルも併せて確認
  • 2Vチャンバまでの回路の屈曲 → 屈曲を解除
  • 3Vチャンバまでの凝固(ダイアライザ内含む) → 膜素材/ヘパリン量を見直し
  • 4回路接続の緩み・クランプ忘れ → 接続とクランプを確認・是正

出血があれば直ちに圧迫止血・ポンプ停止。改善なければ医師へ報告。

その他の主要アラーム

透析液系・安全装置系のアラーム

アラーム原因対応
透析液圧低下脱血不良、透析液回路のリーク、供給ポンプ故障針先修正/再穿刺、補液速度を落とす、機器点検
気泡検知器作動接続部の緩み、脱血不良による微小気泡、補液ボトルの空打ちポンプ自動停止を確認 → 気泡を安全に除去
TMP異常上昇ダイアライザ内凝血・除水量設定過多・フィルター目詰まり抗凝固剤の見直し、改善なければダイアライザ交換
血液漏れ検知器作動ダイアライザの膜破損、気泡による誤検知排液の血性確認 → 陽性ならダイアライザ交換
初動判断

緊急度別の初動フローチャート

アラームが鳴った
↓
生命に関わる兆候があるか?
(出血・意識レベル低下・重度血圧低下 など)
↓
はい → 緊急対応(ただちに)
・ただちに血液ポンプを停止
・圧迫止血・体位保持など応急処置
・医師・当直CEへ緊急連絡
・バイタルサインを測定・記録
いいえ → 通常対応(まず確認→是正)
・表示内容と回路を確認
・該当箇所を是正(屈曲直し・接続確認等)
・是正後にポンプを再開
・改善しなければ医師/CEへ報告

判断に迷ったら、常に「緊急対応」を優先する。

ヒヤリハット事例

よくある誤対応

「よくあること」という思い込みが、対応の遅れにつながる。

抜針アラームへの対応遅れ

「体動による誤作動だろう」と判断し目視確認を後回しに
教訓:確認より先に「止める・見る」を最優先

頻回の静脈圧上昇を軽視

毎回鳴るからと原因確認せずリセットを繰り返す
教訓:頻回のアラームこそ根本原因を都度見直す

エア検知後クランプ確認省略

ポンプ停止だけ確認しクランプを見ずに気泡除去
教訓:「ポンプ停止」と「クランプ確認」は必ずセットで

原因を確認せずにリセット

表示をリセットして再開を優先し原因を確認しない
教訓:リセット前に「なぜ鳴ったか」を一呼吸おいて確認
