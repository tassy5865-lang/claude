# 04. 透析液と除水

## 透析液とは

血液と半透膜を挟んで接触させる液体。血液中の老廃物・過剰な電解質を拡散によって引き抜き、逆に不足している成分(重炭酸など)を血液側に補う役割を持つ。

- 実際には濃縮液(A液・B液など)を精製水で希釈して作成する
- 患者ごとに電解質濃度(特にK・Ca)を調整した処方を用いることがある

## 透析液の基本組成(一般的な範囲・目安)

製品や施設により処方が異なるため、以下はあくまで一般的な範囲の目安。

| 成分 | 役割 |
|---|---|
| ナトリウム(Na) | 血漿浸透圧の維持。血液のNa濃度に近い値に設定し、急激な浸透圧変化を避ける |
| カリウム(K) | 高K血症の是正のため、血液より低い濃度に設定して拡散でKを除去する |
| カルシウム(Ca) | 骨代謝・副甲状腺機能を考慮し、患者の状態に応じて濃度を選択 |
| マグネシウム(Mg) | 血中Mg濃度の維持 |
| 塩素(Cl) | 電気的中性を保つための陰イオン |
| 重炭酸(HCO3-) | 透析中に生じやすい代謝性アシドーシスを補正する緩衝剤(現在の主流。旧来は酢酸を使用) |
| ブドウ糖 | 透析中の低血糖を防ぎ、糖の急激な移動を抑える |

具体的な数値基準(各成分の標準濃度・許容範囲)を記載する場合は、製品添付文書またはガイドラインを確認してから追記する。

## 除水とは

透析の3つの役割の一つで、体内に蓄積した余分な水分を膜間圧力差(限外濾過)によって除去すること。

- 腎不全では尿がほとんど作られない(無尿・乏尿)ため、食事・飲水で摂取した水分がそのまま体内に蓄積する
- 透析と透析の間(中2日・中1日)に体重が増加し、次回の透析でその増加分を除水する、というサイクルを繰り返す

## ドライウェイト(DW: Dry Weight)

- 体内の余分な水分がなく、かつ脱水にもなっていない「適正体重」のこと
- 除水量の設定基準となる重要な指標
- 高すぎると浮腫・高血圧・心不全のリスク、低すぎると血圧低下・脱水・シャント閉塞のリスクにつながる
- 血圧の推移、浮腫の有無、心胸郭比(CTR)、心エコー所見などを総合的に見ながら定期的に見直される

## 除水の考え方

- 除水量 = 透析前体重 − ドライウェイト(+透析中の飲水・食事分など)
- 除水速度(単位時間あたりの除水量)が大きいほど、循環動態への負担(血圧低下など)が大きくなりやすい
- そのため、除水量が多い場合は透析時間を延ばす、除水パターンを調整する(前半をゆるやかに、など)といった工夫が行われる

## 除水に伴う主な症状

- 血圧低下(除水による循環血液量の急激な減少)
- 筋けいれん(こむら返り)
- 悪心・嘔吐、倦怠感
