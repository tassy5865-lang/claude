# 日機装 DCS-100NX の BV計(血液量モニター)まとめ

出典を明記したうえでの調査ノート。DCS-100NXは日機装社製の多用途透析用監視装置(コンソール)で、標準搭載されているBV計(血液量モニター)についてまとめる。

## 1. DCS-100NXとは

- 日機装株式会社の多用途透析用監視装置(コンソール)。デュアルポンプ方式による密閉容量制御、D-FAS(透析開始〜終了の操作支援)、生体情報モニタリング機能などを搭載 [出典: 株式会社北斗医理科 製品ページ]。
- 熱交換器を搭載し、透析排液の熱エネルギーを供給液側に再利用することで加温ヒーターの消費電力を抑える設計になっている。他社コンソール(GC-110N/TR-3300MA)との比較試験では、全工程消費電力がDCS-100NX 1.17kWhに対し他社1.5〜1.6kWh台という報告がある [出典: 細木ほか「日機装社製コンソールDCS-100NXと他社コンソールにおける消費電力の比較」医療法人社団スマイル博愛クリニック]。

## 2. BV計の測定原理

- **近赤外光反射方式**: 血液回路に近赤外線を照射し、反射光の強度変化から循環血液量の変化(血液濃縮度)をモニタリングする [出典: dcs-100nx.com「BV(ブラッドボリューム)計による再循環率測定」]。
- 薬剤(生理食塩水)や専用回路を使わず、コンソール本体のキー操作のみで測定できるのが特徴 [出典: 東邦大学医療センター大森病院 臨床工学部の評価報告]。
- **シングルニードル(単針)透析中は使用不可**という制約がある [出典: dcs-100nx.com]。

### BVplus(新型)での機能拡充

- 従来型は近赤外光の**反射光**のみを利用していたため、ΔBV(血液濃縮度の変化率)と再循環率の測定にとどまり、実血流量は測定できなかった。
- 新型「BVplus」では**レーザードップラー方式**を追加搭載し、実血流量(LDQb: 体外循環血流量)とヘマトクリット値(Ht)の測定を装置一体型で可能にした [出典: DCS-100NXに新機能!? (oompa-de-loompa.blogspot.com, 2018年8月)]。

## 3. BV計(BV-PLUS)の主な機能

日機装のBV計は、同社の血液量モニター機能群「BV-PLUS」として、以下の7項目で構成される(尾道市立市民病院の報告より。同院はDCS-200Siでの導入報告だが、DCS-100NXも同系統のBV-PLUS機能を搭載する)。

| # | 機能 | 内容 |
|---|---|---|
| ① | ΔBV(循環血液量変化率)の測定 | 透析中の血液循環量の変化率を測定。設定値で警報を発生させることが可能 |
| ② | ΔBVリファレンスエリアの表示 | 標準的なΔBVの範囲を画面上に表示 |
| ③ | PRR(Plasma Refilling Rate)の算出 | 血管外から血管内への水分の移動速度を算出 |
| ④ | VA再循環率測定 | バスキュラーアクセスの再循環率を測定し、狭窄などVA機能を確認 |
| ⑤ | BV-UFC(除水速度制御) | あらかじめ設定したΔBVに実際のΔBVが近づくよう、除水速度を自動制御 |
| ⑥ | LDQb(体外循環血流量)の測定 | 血液回路に近赤外レーザー光を照射し、その反射光から求めた血球成分の移動速度を基に算出した血流量 |
| ⑦ | ヘマトクリット値の測定 | 血液回路に近赤外レーザー光を照射し、透過光強度の変化を基に算出 |

出典: 楢原ほか「日機装社製血液量モニター(BV-PLUS)の活用により血圧低下および除水困難症例が改善した1例」尾道市立市民病院 MEセンター・腎センター(尾道市病医誌 Vol.36 No.2, 2023)

### PRR(Plasma Refilling Rate)の計算式

```
PRR = (測定区間の除水量 + 測定区間の循環血液量増加量) / 測定区間の時間
測定区間の循環血液量増加量 = 循環血流量 × 測定区間のΔBV変化率
測定区間の時間 = 60秒(固定)
```

出典: 同上(引用元は日機装株式会社 多用途透析用監視装置 DCS-200Si 操作マニュアル)

## 4. DCS-100NXでの臨床評価(東邦大学医療センター大森病院)

DCS-100NXに装備されている**濃縮法**と**希釈法**の再循環率測定、および**推定血流量モニタ**の使用評価を行った報告(第48回東京都透析医会学術集会発表)。

### 対象・方法

- バスキュラーアクセスに問題のない透析患者が対象
- 再循環率測定: 10症例(透析開始1時間後に除水を停止し、同一患者で濃縮法・希釈法の両方を測定)
- 推定血流量測定: 25症例(血流量150/200/250/280 mL/minの設定に対し、透析開始〜終了まで30分毎に測定)
- 比較対照として、専用機器HD02による再循環率・実血流量も同時測定

### 結果: 再循環率測定

| 測定法 | 平均再循環率 |
|---|---|
| DCS-100NX 濃縮法 | 0.6% |
| DCS-100NX 希釈法 | 3.9% |
| HD02(対照) | 0.0% |

- **濃縮法はHD02と同等の結果**。希釈法は他の2法より高い値を示した。
- 濃縮法は薬剤(生理食塩水)や専用回路が不要で、キー操作のみで測定できる簡便性から**スクリーニングに有効**と考察されている。

### 結果: 推定血流量モニタ

- 推定血流量は、いずれの設定流量(150〜280 mL/min)においても**実流量より高い値**で推移し、過大評価される傾向が確認された。
- そのため「軽微な脱血不良状態では推定血流量モニタは感知しにくい」「モニタで脱血不良を感知した場合は、表示値よりも高い脱血不良が実際には起きている」と考察されている。

### 結語

> 100NXの再循環率は有用だが、推定血流量は実血流に対し過大評価であることを認識した上で活用する必要がある。

出典: 髙橋ほか「日機装社製DCS-100NX装備の再循環率および推定血流量モニタの使用評価の検討」東邦大学医療センター大森病院 臨床工学部・腎センター

## 5. 血圧低下・除水困難への活用事例(尾道市立市民病院)

DCS-200SiのBV-PLUS(ΔBV測定・PRR算出)を活用し、透析中の血圧低下・除水困難が改善した81歳男性の症例報告。DCS-100NXでも同様のΔBV/PRRロジックが使えるため、活用方法の参考になる。

- 生活環境の変化により体重増加量が増大し、除水困難・血圧低下が発生していた症例
- ΔBV低下警報を-12%→-10%に引き上げ、PRRと除水速度が乖離しないよう監視を強化
- 治療開始2時間時点でΔBV −10%付近となった際、設定除水速度0.86 L/hに対しPRRが0.52 L/hしかなく、除水速度を0.50 L/hへ変更
- 以降PRR・ΔBV・血圧経過を注視しながら除水速度をコントロールした結果、急激な血圧低下なく予定時間通りに治療を完遂

出典: 楢原ほか、尾道市立市民病院(前掲)

## 6. 使用上の注意点(まとめ)

- シングルニードル透析中はBV計を使用できない
- 推定血流量モニタは実血流量より過大評価される傾向があるため、脱血不良の検知には注意が必要(表示値以上に脱血不良が進んでいる可能性)
- 濃縮法による再循環率測定はスクリーニングとして有用だが、希釈法は過大評価傾向があるため解釈に注意
- BV-UFC(自動除水制御)を使う場合も、PRR・ΔBVの推移を見ながら手動調整が必要になる場面がある(尾道市立市民病院の事例)

## 7. ΔBV評価の生理学的背景と代替評価法

出典: 日機装セミナー(書き起こしメモ、講師名・開催回は本メモ作成時点で未特定)。文中で言及される「血管内脱水時の代償反応に関する総説」および「総タンパク濃度からΔBVを推定する報告」は、セミナー内で紹介されたものだが著者・誌名は未確認のため、あくまでセミナー講師の説明として扱う。

### なぜ透析中にHt変化(ΔBV)を測定するのか

大きく2つの目的がある。

1. **除水に伴う体液(ΔBV)の変化を見る**(本節で詳述)
2. (再循環率測定など、他の用途は本ファイル1〜6章を参照)

### 体液分布と除水のメカニズム

- 体液は「血液(血管内、血球+血漿)」「間質」「細胞内液」の3つに大別される。
- 尿量低下により体内に水分が貯留する透析患者では、貯留する水分の多くは**間質**に溜まる。
- 除水は血管内(血漿)から直接水分を抜く操作だが、それに伴い間質の水分が血管内へ移動する(**プラズマリフィリング**)ことで、間質の余剰水分を間接的に除去しつつ循環動態を安定させる、というのが透析除水の基本メカニズム。

### プラズマリフィリングの仕組み

- 除水で血液が濃縮すると、アルブミンなどによる**膠質浸透圧**が上昇する。
- 膠質浸透圧の上昇が間質から血管内への水分移動(プラズマリフィリング)を促進し、血管内の脱水を軽度に抑える。
- **プラズマリフィリングレート(PRR)が大きい場合**: 間質から血管内への水分補充が速く、除水をしても血管内脱水は軽度で済む。
- **PRRが小さい場合**: 血管内への水分補充が追いつかず、間質水分はあまり動かないまま血管内の水分だけが減少し、血管内脱水・血圧低下が生じやすくなる。

### 血管内脱水に対する生理学的代償反応

週3回・4時間という標準的な透析は、生体の腎臓による体液調整と比べて短時間で急激な変化を強いるため、血管内脱水が生じやすい。これに対する代償反応は以下の順で生じるとされる(セミナー内で紹介された総説より)。

1. 容量血管である**静脈の収縮**により静脈容量を減少させ、心臓への還流量を増やして脱水を補う
2. さらに脱水が進むと**心拍出量の増加**(心収縮力・心拍数の増加)で代償する
3. それでも不十分な場合、抵抗血管である**動脈系の収縮**により末梢血管抵抗を増大させる

これらは、各臓器へのガス交換・溶質供給という循環系の主目的を維持するための合目的な反応と説明されている。

### ΔBV評価の前提条件

- ΔBVは、血漿成分の減少により相対的に赤血球の割合が増加することを利用した指標である。
- そのため、ΔBVで血管内水分量を評価するには**血球成分量が変化しないこと**が前提となる。輸血や出血がある場合はΔBVによる評価はできない。

### ΔBVパターンの解釈

- **ΔBVの変化が小さい場合**: 除水速度が低い、または体液過剰でプラズマリフィリングが良好(間質の水分量が多い)状態が考えられる。
- **ΔBVの変化が大きい(急激な濃縮)場合**: 除水速度が速い、移動すべき間質水分量が少ない、血管内の膠質浸透圧が低い、炎症などで血管内に水分を維持しにくい、といった要因が考えられる。

### ΔBV計がない場合の代替評価: 総タンパク(TP)濃度による推定

- 透析前後の総タンパク(TP)濃度から血漿量の変化量を計算できるとする報告がある。
- 同一除水量・同一患者で比較すると、Ht濃縮率よりもTP濃縮率の方が高くなる。これはHt濃縮が「血液量」の変化であるのに対し、TP濃縮は「血漿量」の変化であり、分母(基準とする体積)がTPの方が小さいため。
- TP濃縮率から透析終了後のHt値を予測すると、実測よりもやや高めに予測される傾向があるが、両者には相関があるため、ΔBV計がなくてもTP濃縮率等である程度の評価は可能と考えられている。

### プラズマウォーターインデックス

- 血漿タンパク濃縮率を体重変化率で除することで「プラズマウォーターインデックス」が得られ、これがドライウェイト評価の指標になり得るとする報告がある。
