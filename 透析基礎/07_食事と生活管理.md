# 07. 食事と生活管理

透析患者は腎臓による老廃物・水分・電解質の調整ができない(または乏しい)ため、食事・生活面での自己管理が治療の一部として重要になる。

出典: 日本透析医学会「慢性透析患者の食事療法基準」(2014年版)

## 血液透析(HD)患者の食事療法基準

標準体重(kg)あたりの1日量として示される。

| 項目 | 基準値 | 理由・考え方 |
|---|---|---|
| エネルギー | **30〜35 kcal/kgBW/日** | 透析による異化亢進を補い、低栄養(PEW: protein-energy wasting)を防ぐ |
| たんぱく質 | **0.9〜1.2 g/kgBW/日** | 透析でアミノ酸が失われるため、腎不全保存期より多めに必要。ただし摂りすぎはリン負荷につながる |
| 食塩 | **6g未満/日** | 過剰摂取は口渇→水分過剰摂取→体液貯留・高血圧につながる |
| 水分 | **できるだけ少なく** | 具体的な数値目安ではなく、体重増加を指標に個別管理する(無尿の場合は特に厳格) |
| カリウム | **2000 mg以下/日** | 高カリウム血症は不整脈・心停止のリスクがあるため厳格に管理 |
| リン | **たんぱく質(g)×15 mg以下** | たんぱく質摂取量に比例して増えるため、たんぱく質とのバランスで管理する |

## 腹膜透析(PD)患者の食事療法基準

PDは持続的に除水・除去が行われるため、HDと基準が異なる項目がある。

| 項目 | 基準値 | HDとの違い |
|---|---|---|
| エネルギー | **30〜35 kcal/kgBW/日**(腹膜から吸収されるブドウ糖分を含む) | 透析液由来のカロリー吸収を考慮する必要がある |
| たんぱく質 | **0.9〜1.2 g/kgBW/日** | HDと同様 |
| 食塩 | **PD除水量(L)×7.5 + 尿量(L)×5 (g/日)** | 残存尿量・除水量に応じて個別に算出 |
| 水分 | **PD除水量+尿量** | HDのような「できるだけ少なく」ではなく、実際の除水・尿量に応じて設定 |
| カリウム | **制限なし** | 持続的な除去により高カリウム血症になりにくいため |
| リン | **たんぱく質(g)×15 mg以下** | HDと同様 |

## 水分・体重管理の考え方

- 透析間の体重増加は、そのほとんどが摂取した水分(食塩摂取に伴う口渇も含む)によるもの
- 体重増加が大きいほど、次回透析での除水量・除水速度が増え、血圧低下などのリスクが高まる([04_透析液と除水.md](04_透析液と除水.md)参照)
- 体重増加率の目安(中1日・中2日でのパーセンテージなど)は施設・主治医の方針によって示され方が異なるため、具体的な数値基準は担当医療機関の指導に従う

## 生活管理上の注意点

- **シャント管理**: シャント側の腕での血圧測定・採血・重い荷物を避ける、日々のスリル/シャント音の自己チェック
- **感染予防**: 穿刺部・カテーテル出口部の清潔保持
- **運動**: 過度な安静はフレイル・サルコペニアを招くため、体調に応じた適度な運動が推奨される
- **服薬管理**: リン吸着薬など食事に合わせて内服するタイミングが重要な薬剤があるため、[06_合併症と薬剤.md](06_合併症と薬剤.md)と合わせて理解する
