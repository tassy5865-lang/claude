# 09. シャント管理とトラブル対応

出典: `shunt_basics.pptx`(透析未経験看護師・新人臨床工学技士向け研修資料)を基に整理。
バスキュラーアクセス(VA)の基礎、観察のポイント、代表的なシャントトラブルをまとめる。基本的な種類([03_透析の仕組みと回路.md](03_透析の仕組みと回路.md))を踏まえた発展的な内容。

## バスキュラーアクセス(VA)とは

血液浄化(血液透析など)を施行するために必要な、血液の出入り口。血液透析患者にとって必要不可欠なもの。

- **シャント**: 動脈と静脈が短絡を形成するVA
- **非シャント**: 短絡を形成しないVA

## VAの分類

| 種類 | 概要 |
|---|---|
| AVF(自己血管内シャント) | 動脈と静脈を外科的に吻合したVA。動脈の血流が直接静脈に流れ込む。VAの中で最も割合が多く、開存性に優れている |
| AVG(人工血管内シャント) | 人工血管を移植し、動脈・静脈それぞれに吻合したVA。動静脈が細いなどAVFが作製できない場合に適応 |
| 動脈表在化(非シャント) | 筋膜下を走行する動脈を外科手術で皮下組織内に持ち上げ、穿刺しやすくしたもの。動静脈の短絡は作らず、返血用の静脈が別途必要。心機能不良などで内シャントが作製できない場合に適応 |

超音波検査はVAの機能・形態を評価し、管理や治療方針に活用できる情報を提供する目的で行われる。

## 血管解剖(上肢)

VAの構造・異常部位を把握するための土台となる知識。

**動脈**: 鎖骨下動脈 → 腋窩動脈 → 上腕動脈 → 橈骨動脈・尺骨動脈 → 深掌動脈弓・浅掌動脈弓

**静脈**:
- 表在静脈(シャント吻合部に用いられる皮静脈): 橈側皮静脈(AVF吻合部としてよく用いられる)、尺側皮静脈、副橈側皮静脈、肘正中皮静脈
- 深部静脈: 腕頭静脈 ← 鎖骨下静脈 ← 腋窩静脈 ← 上腕静脈 ← 橈骨静脈・尺骨静脈

## 身体所見によるシャント観察

視診・触診・聴診によって、血流の程度や病変部位をおおまかに推測できる。

### 視診

| 所見 | 疑われる病態 |
|---|---|
| 腫脹・皮下血管拡張・顔面浮腫 | 静脈高血圧症 |
| 全体的な浮腫 | 低栄養/静脈高血圧症/体液量過剰 |
| 手指の潰瘍形成 | スチール症候群/静脈高血圧症(ソアサム症候群) |
| 発赤 | 感染/血栓性静脈炎/接触性皮膚炎 |
| 膨隆 | 真性瘤/仮性瘤/血管の蛇行/血腫/血清腫/感染 |
| 手指・爪の色調不良 | スチール症候群/末梢循環障害 |
| 母指球の萎縮 | 手根管症候群 |
| 凹んでいる部分 | 狭窄/血管の蛇行 |

### 触診

| 所見 | 疑われる病態 |
|---|---|
| 拍動性(断続的)に触知 | 中枢側の狭窄・閉塞 |
| 局所のスリルを触知(1本指で評価) | その近傍の狭窄 |
| スリルの減弱・血管の虚脱 | 末梢側の狭窄・閉塞 |
| 血管そのものが硬い | 血栓形成・石灰化沈着・壁在血栓など |
| 瘤が拍動性に触知 | 瘤の中枢側に責任病変の疑い |
| 血管が硬い/スリル・拍動が消失 | シャント閉塞が考えられる |

※ スリルは3本指で全体評価、1本指で局所評価(狭窄が疑われる部位の特定)を行う。

### 聴診

| 所見 | 疑われる病態 |
|---|---|
| 高調音 | その部位の狭窄病変 |
| 拍動音(断続的) | 中枢側の狭窄・閉塞病変 |
| 中枢側まで届く大きな音 | 過剰血流 |
| 微弱な音 | 低血圧/脱水/動脈硬化など |

※ 高調音が聴取される部位でも狭窄を認めない場合、狭窄があっても高調音を聴取しない場合もあり、所見のみで確定診断はできない。

## 主なシャントトラブル

### 脱血不良

所定の血流量がVAから脱血できない状態。透析治療で最も多く遭遇する異常所見のひとつ。

- 穿刺部位の血流量低下(吻合部〜脱血穿刺部位間の狭窄・閉塞、側副静脈の存在、流入動脈の狭窄・閉塞、中枢動脈の狭窄・閉塞、脱水・低血圧・心機能低下などの全身状態)
- 穿刺針外套が正しく血管内に留置されていない(狭窄部・血栓・血管壁・静脈弁に先端が当たっているなど)
- 透析用血液回路内の異常

### 静脈圧の上昇

返血部位の血管内圧が上昇すること。

- 返血穿刺部(針先近傍)、もしくはより中枢側の狭窄・閉塞
- 血液回路内の異常
- Qb(血流量)に比して返血穿刺針のサイズが小さい場合
- 血管蛇行・隔壁・血管荒廃により穿刺針外套の先端が血管壁に当たっている場合
- 過剰血流による相対的な血管内圧上昇

※ 脱血部と返血部の間に狭窄病変がある場合、静脈圧の異常所見が出にくいことがある(末梢側での脱血・中枢側での返血では静脈圧は上昇しない)。

### 再循環

返血された血液の一部または大半が、脱血部位から再度透析用血液回路側に引き込まれる現象。再循環した割合を再循環率と呼ぶ。

- 目安: 概ね**10%以上**の再循環率がある場合は原因を精査する
- 影響: 脱血不良に気づきにくくなる/除水の経過に伴う回路内濃縮/著しい透析効率の低下
- 主な要因: 脱血部・返血部の位置関係、その間の血管の狭窄・閉塞など

### 止血困難

抜針後の止血に要する時間が長くなること。

- 穿刺部位より中枢側の狭窄・閉塞(止血部位の血管内圧上昇)
- 抗凝固薬・抗血小板薬による影響
- 皮膚・血管の状態(皮膚の脆弱、血管壁の荒廃、皮膚から血管までの距離が短いなど)

### 穿刺困難

血管内の適切な位置に穿刺針を留置することが困難であること。

- **内針を挿入できない場合**: 狭窄、閉塞、壁在血栓、血管壁の石灰化、血管径が小さい/深い、血流量の低下、穿刺技術など
- **穿刺針外套が進まない場合**: 狭窄、閉塞、壁在血栓、静脈弁、血管の蛇行、血管隔壁、穿刺技術など

## まとめ

- VAは血液透析の生命線。シャントが使えなければ透析治療自体が継続できない
- 動静脈が短絡を形成する「シャント(AVF/AVG)」と、短絡のない「非シャント」に大別される
- 上肢の血管解剖を理解することが、VAの構造・異常部位を把握する土台になる
- 視診・触診・聴診によって血流の程度や病変部位をおおまかに推測でき、早期発見につながる
- 基礎知識の多職種(看護師・臨床工学技士)での共有が、超音波検査による精密な評価と合わせて安全な透析管理を支える
