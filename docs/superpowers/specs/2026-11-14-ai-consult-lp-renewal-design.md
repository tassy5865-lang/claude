# ai-consult-lp リニューアル設計（Nexsist）

日付: 2026-11-14 ／ 対象: `ai-consult-lp/`（公開URL `https://tassy5865-lang.github.io/claude/ai-consult-lp/`）
前回スペック: `docs/superpowers/specs/2026-09-18-ai-consult-lp-design.md`

## 1. 目的と理由

2026-09 に「AIコンサル（業務自動化ツール開発／AI活用伴走）」として公開したLPを、その後の実績に合わせて作り直す。
9月以降、実際の仕事は **HP制作・予約システム・LINE公式／Lステップ構築** に広がった（琥珀サロン案件など）。今のLPは「AIコンサル」としか読めず、いま受けられる仕事を伝えられていない。
あわせて見た目を「かっこよく」刷新する（本人の言葉）。

## 2. ゴール／非ゴール／やってはいけないこと

**ゴール**
- 屋号 **Nexsist** のサービスサイトとして、「WEB・LINE・AI をまとめて任せられる人」と一目で伝わる。
- 4つのサービス（HP制作／予約システム／LINE公式・Lステップ構築／AIツール開発・業務自動化）が並ぶ。
- 最新の実績（琥珀サロン、Lステップ連携、自作AIツール）が載る。
- 相談の入口は今どおり LINE とフォーム。

**非ゴール**
- 料金表は載せない（本人決定：「まずは相談で」）。
- 公開URL・フォルダ名（`ai-consult-lp/`）は変えない。
- フォームの送信先 GAS（`gas/contact-form.gs`、2026-11-14 デプロイ済み）と `main.js` の送信処理・`GAS_ENDPOINT` は変えない。
- ビルド工程やフレームワークは入れない（静的 HTML/CSS/JS のまま）。

**やってはいけないこと（事実ベース方針、前回から継続）**
- 裏付けのない成果・数値（「売上○%」「時間短縮」「導入社数」等）を書かない。
- 実績の「できること」は実装・公開済みの機能だけ。開発済みでも本番運用前のものは、そうと分かる書き方にする。
- Lステップ連携の相手先名は出さない（本人決定）。

## 4. ページ構成と内容

### ヘッダー
- ロゴ「NEXSIST」（文字ロゴ）。ナビ：サービス／実績／流れ／相談する（ボタン風）。
- スマホ幅ではナビを畳むか、最低限「相談する」だけ残す（作り手判断）。

### ヒーロー
- 大英字「WEB. LINE. AI.」。
- コピー（仮）：「お店の集客と予約を、まるごと仕組みに。」
- サブ（仮）：「ホームページ・予約システム・LINE公式／Lステップ・AIツールまで。ひとりの担当者が、設計から運用までつなげて作ります。」
- CTA：「LINEで相談する」（`https://lin.ee/5SAPZeC`）／「実績を見る」（#works）。

### 悩み（任意・短く）
今の「こんな悩み」4枚は AI 寄り。残すならお店向けに書き換える（例：予約がDM・電話でバラバラ、HPが古く更新できない、LINEを開設したが使えていない、手作業が多い）。残すかどうか・枚数は作り手判断。

### SERVICE（4つ）
1. **ホームページ制作** — スマホで見やすい店舗・事業サイト。更新用の管理画面つきにも対応（琥珀で実装済み）。
2. **予約システム** — 空き枠表示・予約受付・確認メール・リマインド・管理画面（メニュー・クーポン・顧客・分析）。琥珀向けに開発済み。
3. **LINE公式・Lステップ構築** — あいさつ・キーワード自動応答・リッチメニュー（自社 LINE 公式で構築済み）、Lステップ連携（実績あり）、予約システムとの LINE 連携（琥珀向けに開発・テスト環境で確認済み）。
4. **AIツール開発・業務自動化** — 帳票 OCR、営業リサーチなど反復作業を AI で。

旧サービス「AI活用コンサル・伴走支援」は独立カードにせず、「作って終わりにせず、運用まで伴走」という一文で全体に添える。

### WORKS（実績）
- **CASE 01（大カード）琥珀（こはく）｜アロマサロン** — HP・予約システム・LINE 連携。
  - 公式サイト：公開中 `https://tassy5865-lang.github.io/kohaku-site/`。来店の流れ・メニュー料金・FAQ・アクセスを一ページに。店主が自分で文言・写真・メニューを直せる管理画面つき。GA4 で予約・LINE・地図クリックを計測。
  - 予約システム：開発済み（空き枠・予約・確認メール・リマインド・管理画面）。**本番切替前**（デモ公開 `https://tassy5865-lang.github.io/claude/kohaku-booking/index.html`）。公開版は `GAS_URL` が空のデモ表示で、店の実データやメール送信にはつながらないのでリンクしてよい。
  - LINE連携：確認メールのリンクから LINE と連携してマイページに入る仕組みを、テスト環境の実機で確認済み（2026-10-27、main 反映済み）。LINE トーク内で予約する機能（`feature/line-reservation`、未push・実機未確認）は**載せない**。
  - スクリーンショット：`portfolio/assets/work-kohaku.png`（2026-10-11 撮影）。その後サイトに変更が入っているので、今の公開ページと見比べて古ければ撮り直す（作り手判断）。
- **CASE 02（小カード）Lステップ連携の構築**（匿名）— 内容の詳細は未聴取。具体的な機能は書かず「LINE公式アカウントとLステップの連携を構築」程度にとどめる。
- **TOOLS（小カード）自作 AI ツール** — AI-OCR／営業AI社員／FileData。今のカードの「こんな課題に／できること」文面とリンクをそのまま流用（短くしてよい）。

### FLOW
今の4ステップ（ヒアリング→提案→開発・伴走→運用）を流用。文言は「ツール」→「仕組み」等、新サービスに合うよう軽く調整。

### CONTACT
今の LINE（ボタン＋QR `assets/profile-qr.png`）＋フォームをそのまま。**フォームの `name` 属性・ハニーポット欄 `website`・`maxlength`・`#contact-form`/`#form-status` の id は変えない**（`main.js` と GAS が依存）。見た目だけ新デザインに合わせる。

### フッター
© Nexsist / 運営：田代裕貴。リンク：自己紹介（`../自己紹介HP/v2/`）／制作実績（`../portfolio/index.html`）／LINE公式。

## 5. メタ情報

- `<title>`・description・OGP・Twitter カードを Nexsist ＋新サービスの文言に更新。canonical は同じ URL。
- OGP 画像 `assets/social-card.png` を新デザインで作り直す（`assets/build-og-card.py` を更新して再生成、1200×630）。
- JSON-LD：ProfessionalService の name を Nexsist に、`hasOfferCatalog` を4サービスに。Person（田代裕貴、自己紹介HP v2 の @id）は provider として残す。
- favicon は新デザインに合わせて差し替えてよい（作り手判断）。

## 6. 制約

- 静的 HTML/CSS/JS、ビルド不要。ファイル構成（`index.html`/`styles.css`/`main.js`/`assets/`）は維持。
- **CSP（`index.html` の meta）を守る**：外部はGoogle Fonts（CSS/フォント）と GAS への送信のみ。新たな外部 CDN・外部スクリプトを足さない。画像は自前 `assets/` に置く。
- Web フォントは今の Inter／Noto Sans JP の範囲で（太い見出し用に Inter 800/900 のウェイト追加は可）。
- スマホ幅で横スクロールが出ないこと（大英字は `clamp()` 等で縮める）。
- アニメーションを入れる場合は `prefers-reduced-motion` で止める。縁取り文字は読みやすさのため装飾扱いにし、意味のある見出しは日本語の通常テキストで持つ（`aria` 的にも）。
- セキュリティ確認（本人ルール）：変更後に秘密情報・XSS・CSP・外部依存・個人情報をひととおり確認し、確認済み／未確認を分けて報告する。
- 公開は `origin/main` から作業ブランチ→PR→squash merge（作業ツリーの `feature/line-reservation` には未 push の別作業があるので混ぜない）。

## 7. 作り手に任せること

- 具体的な余白・フォントサイズ・色の値（基調：背景 #06061a 前後、紫 #7b5cff 系、水色 #22d3ee 系）。
- 光の玉・ガラスカードの細部、スクロール時の軽い演出の有無。
- 「悩み」セクションを残すか。
- コピーの最終文言（ただし §2 の事実ベース方針の範囲で。参考サイトの見出しをなぞらない）。
