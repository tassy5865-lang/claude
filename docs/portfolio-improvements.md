# ポートフォリオ改善記録

対象: https://tassy5865-lang.github.io/claude/portfolio/
確認日: 2026-09-13

公開HTMLと既存の未公開修正版を確認し、未公開修正版を引き継いで改善した。

| 優先度 | 公開版の課題 | 改善版の対応 |
| --- | --- | --- |
| 高 | 導入と課題説明が長く、制作実績に到達するまでに距離がある | 導入を短縮。冒頭に実際の制作画面を配置し、詳細を直接開ける構成にした |
| 高 | 実績が文字中心で、完成形が伝わりづらい | 5件すべてに既存の画面画像を掲載。画像から詳細を開けるようにした |
| 高 | 長い機能説明と技術名からメリットを読み取る必要がある | 「困りごと／できること」を共通の形式で表示。技術情報は詳細に集約した |
| 高 | 本文や操作ラベルが小さい | 本文は原則16px、日常的な操作ラベルは原則14px以上、操作領域は44px以上に整備した |
| 中 | 詳細を読んだ後、相談時に制作物名や相談内容を一から記入する必要がある | 詳細に相談リンクを配置。件名・本文へ制作物名と相談用ひな型を設定した。送信は利用者が行う |
| 中 | 分野別に何件あるか把握しづらい | 分野ごとの件数と絞り込み後の表示件数を表示する既存修正を維持した |
| 中 | ナビゲーションから実績へ戻りづらい | デスクトップに実績リンクを追加し、名前から先頭へ戻れるようにした |
| 中 | 詳細表示の画面確認・長文操作が不便 | 詳細に制作画面と説明を追加。開くたびに先頭へ戻し、閉じるボタンをスクロール中も表示するようにした |
| 中 | 追加修正のCSSが重複し、保守しづらい | styles.cssへ整理・分離。既存の静的HTML構成とSITEによる実績編集方式を維持した |

## 維持した既存改善

- キーボードのフォーカス表示、本文へのスキップリンク。
- 詳細表示のEscapeによる終了、フォーカス復帰、背面の操作抑止。
- LINEへの直接リンクと、独立したQRコード表示ボタン。
- 構造化データ、説明文、canonical、SNS共有用テキスト。
- 動きを減らす設定への対応と、画像の遅延読み込み。
- 公開版にあった「すべて無料」「APIキーはサーバー送信なし」といった一律の表現を使わない修正文。

## 確認結果

- 公開ページのHTTP 200を確認。
- JavaScript構文とJSON-LDのJSON形式を確認。
- 5件の制作実績データ、使用する画像6点、CSSの存在を確認。
- ローカル配信でHTML・CSS・画像のHTTP 200を確認。
- 制作物別メールリンクの件名・本文とURL制限処理を確認。
- 主要な本文・アクセント・ボタンの色の組み合わせはコントラスト比5.02〜13.24:1。
- プレビューをブラウザで開き、5件の一覧と相談導線が出力されることを確認。
- モバイル実機、200%拡大、絞り込み・モーダル・QRのブラウザ操作テストは未実施。全リンク先のサービス動作や、メールの送信は検証対象外。

## 今後、実データを用意できれば追加したい改善

- 実測した削減時間・導入前後の比較。根拠のない数値は追加しない。
- 掲載許可がある利用者の声・導入事例。
- 実画面の高解像度画像への更新。既存CSV画像は一部が切り取られているため、全体を見渡せる画像に差し替える余地がある。
