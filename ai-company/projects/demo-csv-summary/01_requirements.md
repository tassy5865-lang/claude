# 要件定義書：demo-csv-summary

## 1. 背景・現状

- 誰が: 架空の総務担当者
- どの作業を: CSVの金額列を手計算で集計
- 頻度: 月1回
- 1回あたり: 15分（ダミー仮定）
- 課題: 転記ミスと再計算の手間

## 2. 理想の状態

CSV文字列を貼り付けると、データ件数と金額合計をブラウザ内で確認できる。

## 3. スコープ

### やること

- [x] ヘッダー付きCSVの貼り付け
- [x] 2列目の数値合計
- [x] 空入力・不正値のエラー表示
- [x] 単一HTML、オフライン動作

### やらないこと

- 引用符内のカンマ、複数シート、ファイル保存、外部API連携

## 4. 制約とデータ取扱い

- 端末/OS: モダンブラウザ
- データ分類: 完全な合成ダミーデータ
- 保存場所: 保存しない。ブラウザメモリのみ
- 外部送信: なし
- Claude Code読取り承認: ダミー案件の全ファイルを2026-08-27に人間承認済みという想定
- 保持・削除: 画面再読込みで消去
- 秘密情報: なし
- バックアップ: 入力元CSVを利用者が保持

## 5. 受入基準

- [x] `項目,金額 / A,100 / B,250` で件数2、合計350を表示する
- [x] 空入力で処理せずエラーを表示する
- [x] 数値でない金額を含む行番号を表示する（空行を挟んでも元の行番号を表示する）
- [x] 合計が数値の範囲を超える場合はエラーを表示する（正常結果として扱わない）
- [x] 外部通信・外部ライブラリがない

## 6. 実装承認

- 承認者: ダミー案件責任者
- 承認日時: 2026-08-27 12:00 JST
