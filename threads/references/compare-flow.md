# 複数投稿の比較（メニュー⑤）

## 集める情報（1問ずつ）
| # | 聞くこと | 補足 |
|---|---|---|
| Q1 | 比べたい投稿（2〜5件） | 本文をまとめて貼ってもらう。各投稿にA・B・C…と名前を付けて返す |
| Q2 | 何を知りたいか | どれが良かったか／なぜ差が出たか／次にどれを伸ばすか／その他 |
| Q3 | 各投稿の数値 | 全投稿でそろっている指標だけを比較に使う。そろっていない指標は参考扱い |
| Q4 | 投稿日時・条件の違い | 曜日、時間帯、画像の有無、連続投稿など。わからなければ飛ばす |

## 比較のルール
- 全投稿に共通する指標だけで並べる。欠けている投稿がある指標は表に「—」と書き、比較の結論には使わない。
- 投稿同士で違う条件（テーマ・型・時間帯・画像など）を一覧にする。条件が複数違う場合、「どれが効いたかは切り分けられない」と明記する。
- 件数が少ない比較は傾向として扱い、法則として扱わない。

## 出力の形
1. **数値の比較表**（投稿×共通指標）
2. **条件の違い表**（投稿×テーマ・冒頭の型・問いかけの有無・文量・投稿日時 など）
3. **データから言えること / 仮説 / 判断不能**（`analysis-flow.md` と同じ区分）
4. **次に試すこと**：変える条件を1つに絞り、他は固定する案
5. 必要なら、一番伸ばしたい投稿の改善版を1つ

最後に「この案で検証を設計しますか？（⑦へ）」と聞く。
