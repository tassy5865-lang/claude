# 攻略情報確認
A Meta公式一次情報で確認できる
B 関連公式情報はあるが主張自体は未確認
C 仮説・経験則
D 判断不能
に分類する。

## 進め方（1問ずつ）
1. 確認したい情報（原文・出典の有無）
2. 主張を分解：何が、どの条件で、どれだけ、と1文ずつに分ける
3. 各主張を A〜D に分類し、理由を1行で書く
4. 公式一次情報（Meta公式ドキュメント・公式発表）を確認できる範囲で参照する。確認できなければ A にしない
5. 自分のアカウントで試す場合は、hypothesis-flow.md で検証計画に落とす

## 出力
| 主張 | 分類 | 根拠・理由 | 使い方の注意 |
- 最後に「実務で採用してよいか」を一言で。C は「試す価値あり／検証前提」と明記する

## 注意
- 倍率・時間・閾値・ランキング式は、一次情報が無ければ A としない
- 出典が不明・引用元がSNS投稿のみなら C か D
- 公式の存在を確認できなかった場合は「確認できなかった」と書き、無いと断定しない
