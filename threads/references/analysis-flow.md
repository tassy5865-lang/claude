# 投稿分析・比較
同じ指標同士だけを比較する。実績データはユーザーが持っているものだけを使い、不明は不明のままにする。

## 質問の順序（1問ずつ）
1. 対象投稿（本文）と投稿日時
2. 手元にある指標（閲覧数・いいね・返信・リポスト・引用・フォロー増など）。無い指標は聞き返さず「不明」とする
3. 比較対象（②④は同アカウントの近い条件の投稿、⑤は複数投稿）
4. 投稿時の狙い（コメント/保存/フォロー等）
5. 気になっている点・仮説

## データが少ない・無いとき
- 指標が閲覧数などごく一部だけでも進める。言えるのは「その指標だけで言える範囲」まで（例：閲覧数に対するいいね率）
- 返信・保存など無い指標は「不明」と書き、狙い（コメント等）が達成できたかは「判断不能」とする
- 「データから直接言えること」が薄いときは、1〜2行で止めて、本文の設計面の確認に時間を使う

## 分析の出力（6区分）
1. データから直接言えること
2. Meta公式情報と照らして言えること
3. 仮説（根拠の強さを添える）
4. 判断不能（なぜ不能か、何があれば言えるか）
5. 次回検証：変える条件は原則1つ、見る指標は1つ
6. 改善版：投稿の改善案（リライトが必要なら rewrite-flow.md）

## モード別の観点
- ③伸びなかった：本文の読者設計（誰の何を考えさせたか）、冒頭、余白、CTAの順に確認。原因は断定せず、候補を絞る
- ④伸びた：再現できる要素と、偶然の可能性を分ける。1本だけで型と断定しない
- ⑤比較：指標を揃え、差が出た要素を本文構造・テーマ・時間帯などで切り分ける。複数条件の差は原因を断定しない

## 比較の中断条件（⑤）
- 比較できる投稿が1本しかない → ③か④に切り替えを提案
- 指標が揃わない → 揃う指標だけで比較し、揃わない分は不明とする
- 差の要因が複数ある（時間帯・テーマ・冒頭など）→ 原因を断定せず、候補を並べて「次回は1つだけ変えて切り分ける」にする

## 禁止
- 取得できない指標の推測補完
- 根拠のない倍率・時間・閾値の適用
- 改善仮説を複数同時に押し付けること（1つに絞る）
