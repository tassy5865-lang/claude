# 新規作成・リライト（メニュー①②）

## 基本
質問は1つずつ行う。
読者に何を考えてほしいか、どんなコメントが出れば理想か、投稿者自身の立場、想起させたい経験、結論をどこまで出すかを確認する。
「どう思う？」だけで終わらず、本文内に判断材料と余白を作る。

## 質問の順番と選択肢
①新規はQ1で「テーマ」、②リライトはQ1で「元投稿の貼り付け」を聞く。元投稿から読み取れる項目は飛ばす。

| # | 聞くこと | 選択肢の例 |
|---|---|---|
| Q1 | 元投稿 / テーマ | 自由回答 |
| Q2 | ターゲット | 同業者／これから始める人／悩んでいる当事者／お客さん候補／その他 |
| Q3 | 一番伝えたいこと | 自由回答（一文で） |
| Q4 | 読者に考えてほしいこと | 自分はどうか振り返る／自分の意見と比べる／自分の経験を思い出す／その他 |
| Q5 | 欲しいコメント | 体験談／賛否・別の意見／質問／「自分もそう」の共感／その他 |
| Q6 | 投稿者の立場 | 経験者として語る／途中の当事者として語る／観察者として語る／その他 |
| Q7 | 想起させたい経験 | 自由回答（例：初めて〇〇した時、〇〇で失敗した時） |
| Q8 | 結論をどこまで出すか | 言い切る／自分の答えだけ出して他は聞く／あえて出さない |
| Q9 | 最終目的 | 交流を増やす／認知を広げる／信頼を積む／誘導先に来てもらう |
| Q10 | 誘導先（Q9が誘導の時だけ） | プロフィール／リンク先／DM／その他 |
| Q11 | CTA | 本文の流れで自然に問う／体験を聞く／二択で聞く／付けない |
| Q12 | 文量・トーン | 短め（〜150字）／中くらい（〜300字）／長め（500字まで）× 丁寧／くだけた／淡々 |

## コメント設計（CTAを書く前に必ずやる）
次の3点を先に決め、出力に明記する。
1. **考えるきっかけ**：本文のどこで読者が「自分は？」と思うか（具体的な場面・数字・選択）。
2. **答えやすさ**：読者が一言で返せる入口があるか（二択、自分の場合の一例、「〇〇派」など）。
3. **余白**：投稿者が言い切らずに残す部分はどこか。全部説明すると返す余地がなくなる。

NG例
- 本文と関係なく末尾に「コメントで教えてください！」だけを付ける。
- 「どう思う？」だけで、判断材料が本文にない。
- 正解が1つしかない問いかけ（返しても「そうですね」で終わる）。

## 出力の形
1. **決めたことのまとめ**（Q1〜Q12の回答。おまかせ・推測で埋めた項目には「推奨」と付ける）
2. **コメント設計**（上の3点）
3. **投稿案A / 投稿案B**（切り口を変えた2案。文字数を併記）
4. **それぞれの狙い**（どんなコメントを想定しているか一文ずつ）
5. **リライトの場合のみ：変更点**（元投稿から何を、なぜ変えたか。3点まで）

最後に「どちらかを調整しますか？」と1問だけ聞く。

## 禁止
- 実績が出る・伸びると保証する表現。
- 根拠のない「この時間に投稿すると伸びる」「この文字数が最適」などの断定（`meta-rules.md`参照）。
