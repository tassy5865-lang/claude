# 透析指標計算・分析

透析患者の1回の治療データから、除水・循環動態・透析効率・貧血/電解質・心機能の各指標を自動計算し、
AI（Claude等）へ医学的考察を依頼するためのプロンプト文をExcel関数で自動生成する臨床用計算ツール。

- 元データ: `透析指標計算・分析.xlsx`（コードなし、Excel関数のみで構成。オリジナル仕様のリファレンス）
- Web版: `index.html`（HTML/CSS/JS単一ファイル、フレームワーク不使用・ビルド不要。ブラウザで開くだけで動作）。[[project_tetris]]や[[project_dragon_quest]]、[[project_taretool]]と同じくビルドレス・ブラウザ完結構成
- 対象読者: このフォルダで作業する将来のClaude — シートを都度バイナリ解析しなくて済むよう、シート構成・主要数式・変数の意味をここにまとめる

**実装済み（v1・コア機能のみ）:** xlsxシート1「除水設定,循環動態管理」＋シート2「透析効率,貧血管理」の計算ロジックを移植。

## 全体構成（4シート）

1. **除水設定,循環動態管理** — 基本情報・体重・血液データを入力し、PWI/mean Kr等の循環動態指標とKt/V(Daugirdas)/URRを算出
2. **透析効率,貧血管理** — Michaels式によるダイアライザ理論クリアランスとQb/KoA変更シミュレーション、貧血(ERI)・電解質(P/K除去率)を算出
3. **PWI.Krグラフ** — シート1のPWI・mean Krを日付ごとに記録してグラフ化する経時トレンドシート
4. **心不全管理** — LVEF分類(HFrEF/HFmrEF/HFpEF)、17区域壁運動スコアリング(WMSI)、弁膜症評価

シート間参照が多いため、**シート名を変更するとリンク切れ（`'除水設定,循環動態管理'!B2`のような式）が起きる**点に注意。

## シート1: 除水設定,循環動態管理

### 入力セル
- B2 透析時間(min) / B3 総除水量(ml)
- B5 透析前体重 / B6 透析後体重(kg)
- B8 透析前TP / B9 透析後TP(g/dL)
- B10 透析前Ht(%)
- B11 透析前BUN(Co) / B12 透析後BUN(Ct)(mg/dL)

### 算出指標と数式
| 指標 | セル | 数式 | 意味 |
|---|---|---|---|
| ΔBW(除水量) | F2 | `B5-B6` | 単純体重差 |
| 体重変化率 | F3 | `F2/B5` | ΔBW/PreBW |
| TP濃縮率 | F4 | `1-(B8/B9)` | |
| UFR(除水速度) | F5 | `B3/B2` | ml/min |
| π1/π2(膠質浸透圧) | F6/F7 | `2.1*TP + 0.16*TP^2 + 0.009*TP^3` | TP1/TP2をそれぞれ代入する3次多項式近似 |
| CPV1(循環血漿量 前) | F8 | `0.077*B5*1000*(1-B10/100)` | 体重の7.7%×(1-Ht) |
| CPV2(循環血漿量 後) | F9 | `F8*(B8/B9)` | CPV1×(TP1/TP2) |
| **PWI** | I2 | `F4/F3`（TP濃縮率÷体重変化率） | Protein-Water Index。**2≦PWI≦4が適正範囲**。<2はDW下げ要、>4はDW上げ要（血管内リフィル能の指標） |
| **mean Kr(プラズマリフィル係数)** | I3 | `(F5-I4)/(F7-F6)` | ml/min/mmHg。**1≦Kr≦4が適正範囲**。<1はDW上げ要、>4はDW下げ要 |
| CPV Rate(血漿量減少速度) | I4 | `(F8-F9)/B2` | ml/min |
| URR(除去率) | I7 | `((B11-B12)/B11)*100` | % |
| Kt/V(Daugirdas) | I8 | `-LN(Ct/Co - 0.008*(t/60)) + (4-3.5*(Ct/Co))*(ΔBW/BWpost)` | 標準Daugirdas式 |

下部（A13以降）にはB列の値からCHAR(10)で連結した**AI考察依頼プロンプト文**を自動生成するセルが2つある（除水・循環動態の考察依頼、透析効率とのバランス考察依頼）。数値を変えるとプロンプト文も自動更新される。

## シート2: 透析効率,貧血管理

### 現在の処方 → シミュレーション
- B2〜B9: 現在の透析時間/DW/実測Kt/V(シート1参照)/Qb/Qd/膜面積/現KoA
- B9 KoA逆算式: `(Qb/(1-Qb/Qd))*LN((1-K/Qd)/(1-K/Qb))`
- B11〜B14: シミュレーション用の変更後Qb/透析時間/KoA/膜面積
- F2 理論クリアランス: Michaels式 `Qb*(EXP(KoA/Qb*(1-Qb/Qd))-1)/(EXP(KoA/Qb*(1-Qb/Qd))-Qb/Qd)`
- F3 実測クリアランス: `Kt/V * (DW*0.6*1000) / t`（Kt/Vからの逆算）
- F4 実効効率係数: `実測K/理論K`（1.0から離れるほど再循環・目詰まり等のロス）
- F7/F8/F9: シミュレーション後の理論K/実測予測K/予測Kt/V
- I2/J2: 実効効率係数と実測Kt/V・Qbから「優先改善アクション」を自動判定（IF分岐: Kt/V≥1.2なら現状維持、効率係数<0.8なら再循環点検、Qb<250ならQb増量、それ以外は膜面積増）

### 貧血・電解質（B17以降）
- B18 Hgb / B19 ESA投与量週(IU/week)
- **ERI** F18: `ESA投与量/体重/Hgb` — 目安10〜15以上でESA低反応性（透析不足・鉄欠乏を疑う）
- B21/B22 透析前後リン、B23/B24 透析前後カリウム
- **PRR(リン除去率)** F19: `(P_pre-P_post)/P_pre*100` — 通常50〜60%程度
- **KRR(カリウム除去率)** F20: 同様の計算式

ここにも複数のAI考察依頼プロンプト（処方最適化レポート依頼、シミュレーション・コンサルテーション、5ドメイン統合の総合カンファレンス評価依頼）が自動生成される。C27〜C30はシート1の値をこのシート内に再掲するための参照セル。

## シート3: PWI.Krグラフ

A/B列に日付とPWI、D/E列に日付とmean Kr（シート1参照）を追記していく経時データ表＋グラフ。新しい透析日のデータを追加する際はこの表に1行追加する運用。日付はExcelシリアル値。

## シート4: 心不全管理

- LVEF(B2)から`IF`分岐でHFrEF(<40%)/HFmrEF(<50%)/HFpEF分類、正式名称、推奨薬（Fantastic Four等）を自動判定
- 17区域の壁運動を1〜4点（Normal〜Dyskinesis）でスコアリングし、WMSI(C24)は`AVERAGE(C8:C23)`で平均算出。各区域には冠動脈支配（LAD/RCA/LCX）も対応付け
- 弁膜症(MR/AR/AS/TR)をNone〜Severeで評価
- A32セルがLVEF分類・WMSI・LVDd・弁膜症の重症度を組み合わせて自然文の解析結果コメントを自動合成する

## 運用上の注意

- 多くの指標セルはESA投与量やリン等が未入力だと`#DIV/0!`になる（意図した挙動。値を入れれば解消）
- シート名（`除水設定,循環動態管理`など、カンマを含む）は他シートから文字列参照されているため変更しない
- このワークブックの目的は「計算するだけ」でなく、算出した数値を埋め込んだ**AI相談用プロンプト文をワンクリックでコピーできる状態にする**ことが核。新しい指標を追加する際は、既存のプロンプト生成セルの書式（`&CHAR(10)&`で改行連結）に倣うと一貫性が保てる
- 実データ（体重・血液データ等）が含まれるファイルなので、内容を外部に共有・アップロードする際は患者情報の取り扱いに注意する
