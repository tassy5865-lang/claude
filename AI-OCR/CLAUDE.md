# CLAUDE.md

This file provides guidance to Claude Code when working with code in this repository.

## プロジェクト概要

画像・PDFファイルをアップロードし、AIでOCR・文字起こしを行い、その結果を既存のExcel台帳へAIが自動振り分けするところまでを1つでこなすWebツール。ヘッダーの「OCR」「Excel振り分け」タブで画面を切り替える2画面構成（内部状態・API設定は共通）。

## 技術スタック

単一HTML（index.html）だが、CDN経由でReact 18 + Babel Standalone（JSXをブラウザ内変換）+ Tailwind CSS + Lucide Icons + PDF.js + SheetJS(xlsx) + PapaParseを使用。OCR・Excel振り分けともにGoogle Gemini API（既定は`gemini-flash-latest`、設定画面で変更可）を直接呼び出す方式。

Gemini APIキーはユーザーがブラウザ内で入力し、localStorageにのみ保存する（サーバー送信なし）。OCR・Excel振り分けの両機能で同じAPIキー・同じ選択モデルを共用する。

## 現在の状態

### OCR画面（領域指定OCR方式）
- PDF/画像アップロード、PDFはページごとにcanvasへ画像化
- 複数ページ帳票の「1レコード＝Nページ」構成をAIが自動判定
- プレビュー画像上でドラッグして抽出領域（バウンディングボックス）を作成・移動・リサイズ
- 「AI自動特定」ボタンで抽出領域そのものをAIに検出させることも可能
- 領域ごとにテキスト／チェックボックス／丸囲みの3種の読み取りタイプを指定可能
- 領域リストの「複製」ボタンから、指定した領域を別の構成ページ（P.1/P.2...）へ複製可能（複数ページ構成の帳票で同じ位置に項目を追加する用途）
- 抽出結果はレコード単位で確認・手動修正でき、CSV一括出力、または後述の「Excel台帳へ振り分ける」ボタンでExcel振り分け画面へ直接連携
- 抽出領域の設定はGoogle Apps Script（GAS）のWebアプリ経由でテンプレートとしてクラウド保存・再利用可能（任意設定。セットアップ手順は[GAS_SETUP.md](./GAS_SETUP.md)、スクリプト本体は[gas/Code.gs](./gas/Code.gs)を参照）

### Excel振り分け画面（2026-08-11、旧`RPA/index.html`を統合・旧ツールは削除）
- 既存Excel台帳（.xlsx）をアップロード。アップロードのたびlocalStorageに新しい「台帳」として自動保存され、複数台帳を切替・名前変更・削除可能（台帳管理モーダル）
- データソースは2通り: ①OCR画面で解析済みなら「AI-OCRの解析結果を読み込む」ボタンでCSVエクスポートを挟まず直接取り込み ②CSVファイルを手動アップロード（複数ファイル一括・列構成一致のもののみ結合）
- 「AIで振り分け実行」でGemini APIがCSV/OCR側の項目をExcel列に意味的にマッピング（表記ゆれ・日付形式を既存データに合わせて整形、1セル内に複数値がまとまっている場合は行を自動分割）
- マッピング結果は表形式で確認・セル編集・行削除可能、「Excelデータに反映」で確認済みデータをメモリ上のExcelデータに追記
- 台帳＋CSV列構成の組み合わせごとにマッピング内容を自動保存し、次回以降は「保存済みマッピングを適用（AI不要）」で即時反映可能。全件横断の一覧・手動編集・削除はヘッダーの「保存済みマッピング管理」モーダルから
- 「Excelファイルをダウンロード」で最新状態を.xlsxとしてダウンロード（サーバー保存なし、ブラウザ完結）
- Gemini構造化出力のスキーマキーには実データ由来の列名を直接使わず、位置ベースの安定キー（Excel列=col1,col2,.../CSV列=field1,field2,...）を使用（空欄・重複列名でのAPI 400エラーを回避するため）

### 共通
- Gemini APIキー・使用モデル（プリセット3種+カスタム入力）・GAS URLは画面右上の設定アイコンから入力（未設定時は赤丸バッジ表示）。選択中のモデル名はヘッダーにバッジ表示
