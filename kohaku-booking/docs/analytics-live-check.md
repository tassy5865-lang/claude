# 分析画面の実機確認 手順書(確認表 34〜38)

テスト用のスプレッドシートとカレンダーで、管理画面の「分析」が実データで正しく動くかを確認します。
**本番のシートでは行わないでください**(テスト予約を入れるため)。所要時間の目安は30〜40分です。

## 準備(オーナーのGoogleアカウントで)
詳しくは `docs/deploy-checklist.md` の「1. GAS(テスト環境)」。要点だけ:

1. 新しいスプレッドシートを作る → 拡張機能 → Apps Script
2. `gas/Code.gs` の全文を `Code.gs` に貼り付け。`gas/appsscript.json` も反映(プロジェクトの設定で「appsscript.json を表示」をON)
3. `Code.gs` 冒頭の `CONFIG` の `OWNER_EMAIL` と `SITE_URL` を入れる(`SITE_URL` は仮でも可)
4. プロジェクトの設定 → スクリプト プロパティ に `ADMIN_PASSWORD` を追加(テスト用の値でよい)
5. `setup` を実行 → 権限を承認(カレンダー・スプレッドシート・メール)
6. デプロイ → 新しいデプロイ → ウェブアプリ(実行=自分 / アクセス=全員)→ URL を控える
7. ローカルの `admin.html` の `CONFIG.GAS_URL` に上のURLを入れ、`npx serve .`(または `python -m http.server`)で開く
   ※ 入れた `GAS_URL` はコミットしないでください(確認が終わったら空に戻す)

3. 実行ログに「テスト予約を 10 行追加しました」と出る。`予約` シートに ID が `TESTA-01`〜`TESTA-10` の行ができる

## 確認する(管理画面 → 分析)
管理画面にログイン(`ADMIN_PASSWORD`)して左(スマホは下)の「分析」を開きます。
期待値は、実行日が月の3日以降ならいつ実行しても同じです(「前期間比」だけ実行日で変わるので確認対象外)。

### 項目34: 今月
| 表示 | 期待値 |

| 売上(実績) | ¥26,000(7,000 + 9,000 + **10,000**。TESTA-03 は割引後の金額) |
| 来店数 | 4件 |

### 項目36: 過去日付の確定
- 今月を表示すると「過去の予約のうち 1件が来店済になっていません(売上に含まれていません)」の注意が出る(TESTA-05)
- TESTA-05 を管理画面の「今日の予約」(昨日に移動)で「来店済」にして分析を開き直す → 注意が消え、売上が ¥33,000、来店数が5件になる
  確認後は `clearAnalyticsTestData` で消えるので戻さなくてよい

### 項目37: 金額が当日案内の来店
- 「金額が未定の来店が 1件あります(売上に含まれていません)」の注意が出る(TESTA-04)
- 売上・客単価の計算に入っていない(26,000÷3=8,667 のまま。4で割っていない)

### 項目38: 期間の不正入力
- 期間指定で開始日を終了日より後にして「この期間を表示」→ 「期間は400日以内で、開始日から終了日の順に…」の案内が出て、画面は壊れない
- 開始日を1年以上前(401日以上)にしても同じ案内
- 日付を空にして押しても画面が壊れない(直前の期間のままになる)

### 追加で見る点
- スマホ幅(実機または開発者ツール)で、カード・棒グラフ・内訳がはみ出さない
- 別の管理者トークン無し(ログアウト後)で分析を開けない
- 同期が遅い/失敗したとき: 「もう一度読み込む」ボタンで再取得できる

## 後片付け
1. Apps Script で `clearAnalyticsTestData` を実行 → 「テスト予約を 10 行削除しました」。`TESTA-` 以外の行は消えません
2. `admin.html` の `GAS_URL` を空に戻す(コミットしない)
3. `TestSeed.gs` は本番のGASには貼らない

## 結果の記録
問題が出たら、項目番号・表示された値・期待値をそのまま共有してください。
`docs/deploy-checklist.md` の34〜38にチェックを付ける際は、上の期待値で判断します。
